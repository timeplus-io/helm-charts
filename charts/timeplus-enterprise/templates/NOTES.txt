{{- if and .Values.timeplusAppserver.enabled (not .Values.timeplusAppserver.encryptionKey) (not .Values.timeplusAppserver.existingEncryptionKeySecret) }}

WARNING: no encryption key is configured for the appserver. Credentials it stores (the Data Agent LLM API key, MCP server secrets) are sealed with a built-in default key that only obfuscates them. Set `timeplusAppserver.existingEncryptionKeySecret` (a Secret with key NEUTRON_ENCRYPTION_KEY) or `timeplusAppserver.encryptionKey` before storing real credentials, and back the key up: switching keys later means re-entering every stored credential.
{{- end }}
